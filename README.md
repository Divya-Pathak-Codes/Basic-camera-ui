# Basic-camera-UI
My first camera UI project, created while learning and practicing HTML and CSS.

## About the project
This project is a basic camera user interface created using HTML and CSS.
I built it to practice webpage structure, styling, layouts, and basic UI design.

## Technologies Used
- HTML5
- CSS3

## Features 
- Camera-style user interface
- Responsive layout
- Navigation menu
- Gallery, shortcuts, Exhibits, Events, Store, Contact and Feedback sections
- Background image and custom styling

## Purpose

This was one of my first projects while learning web development.
It helped me understand how HTML and CSS work together to create a user interface.

## What I Learned

- CSS styling
- Positioning and layouts
- Using background images

- Connecting HTML with external CSS
